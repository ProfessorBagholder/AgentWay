# Automatic receiver outbox stream

Status: merged in PR #23, 2026-09-24 UTC. This is a shared notification transport for the dormant **automatic** delivery outbox. It does not establish a verified binding, start a native agent, or enable automatic handoff for normal connections. The supported handoff mode remains the pull inbox; its separate [agent task stream](handoff-task-stream.md) uses the agent credential and sends pull-task hints.

An owner-enrolled transport adapter can open `GET /v1/handoff-receiver/deliveries/stream` on the agent API host using **its receiver-scoped bearer token**, `Accept: text/event-stream`, and optionally `Last-Event-ID`. An agent task or publishing credential cannot open this stream. Each `delivery-available` event has the durable outbox row cursor as its SSE `id` and carries only `protocol_version`, `delivery_id`, `task_id`, `kind`, `binding_generation`, and `expires_at`. It contains no task instructions, result, native target, native run reference or credential. The receiver must use the authenticated [delivery feed and admission route](handoff-delivery-foundation.md) to re-read current state before invoking any native target. Admission remains distinct from native agent acceptance and sender result receipt.

The stream filters to the token's connection and binding generation, checks current binding enablement, task state, grant and delivery deadline, and revalidates the token at least every five seconds and before sending a newly found batch. Rotation or disconnection closes the socket. It shares a 32-connection limit with the pull-task stream, sends 15-second heartbeat comments, disables proxy buffering, and polls the SQLite outbox at one-second intervals. A bad cursor returns 400; a cursor ahead of a restored database resets to zero. Reconnect with backoff and the last processed event ID; also page the durable delivery feed on startup and after reconnect. SSE progress is a notification cursor, not an admission receipt or a complete recovery snapshot.

An outbound stream can reach an adapter in a cloud-hosted or local environment without exposing that host to inbound traffic. A product edge must still provide a supported way to wake the **intended existing agent**, return its authenticated claim/result, and wake the original sender for result acknowledgment. The same native conformance test applies to every agent product before any automatic-ready label is shown. An open stream or transport admission alone does not satisfy that test.
