# Native receiver compatibility — Phase 0

Status: partial live feasibility, 2026-09-23. **One same-conversation Codex scheduled pickup is verified; no product has passed the full bidirectional handoff suite.** A product being able to call AgentWay's MCP server proves outbound access, not inbound delivery. The [2026-07-28 MCP specification](https://blog.modelcontextprotocol.io/posts/2026-07-28/) does not supply an unsolicited server-to-idle-agent turn; its multi-round-trip requests occur in the course of a client call. This matrix is a feasibility inventory for thin integrations against the [common AgentWay receiver protocol](handoff-receiver-contract.md); it is not a list of different handoff features or a basis for choosing a product-specific architecture. Recheck product availability and documentation at implementation time.

The first Grok Bot → AgentWay → Codex test was a **manual pull-inbox** result: Grok Bot created task `80774cfa-1d40-444d-bd95-445ba7633d51`, and Codex completed it after the owner relayed the ID. The later scheduled heartbeat received task `8387e338-6d2b-4272-b1e6-2924eaaaca78` in this Codex conversation without ID relay. Grok Bot read the result while already active. Neither run establishes idle Grok pickup or automatic return to an idle sender. No publishing action is needed for the next probes.

## Gate and immediate next action

Phase 0 has **not exited**: the [universal receiver requirements](handoff-receiver-contract.md) and [reusable conformance scenario](handoff-conformance-v1.md) are defined, but full wire schemas are not frozen and no product has demonstrated both idle pickup and return to an idle sender. The strongest currently documented direct external trigger is the Workspace Agents API, but that is a separately configured ChatGPT product. Grok Bot's same-Bot routine remains an untested candidate; Codex's same-thread schedule has passed one pickup probe. They do not alter AgentWay's common states or release bar. The next action is to test an idle Grok receiver and return to an idle sender with native transcript and AgentWay receipt evidence, timestamps, deduplication and failure recovery. If an advertised product cannot meet that scenario, resolve product scope with the owner; do not ship a weaker handoff for it or a privileged subset by default.
